# Project Description:
- This repository is for our website QuiC, it provides a fast, paperless way to create, store, and share flashcards easily. With an account, you can save your study materials and organize them into sets. This is designed to make studying more faster, simpler, and more efficient for exams, quizzes, learning a new topic, or reviewing on the go.

# Prerequisites:
- Docker must be installed on your system to run locally.

# How to Run the Program:
- Go to localhost:3000 on your current browser
- In any VS Code or any editor, go to the terminal and direct yourself to the folder called docker-compose.yaml.
- To run: docker compose up
- To end: docker compose down
- To end and reset everything: docker compose up -v
- Wait a few seconds and you should be able to view the website.

# How to Run the Tests:
- In your text editor, direct yourself to the docker-compose.yaml file inside of the ProjectSourceCode folder.
- Near the bottom of the docker-compose.yaml file, make sure command is set to 'npm run testandrun'
- To run: docker compose up
- This is will run all test cases and then run the program on localhost:3000 if all tests pass
